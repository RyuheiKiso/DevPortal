# C# テンプレート群

DevPortal の Backstage **Software Templates**（scaffolder）のうち、C# / .NET 向けのものをまとめたディレクトリです。

| テンプレート | 用途 |
| --- | --- |
| [`backend/`](backend/README.md) | C# (.NET 10) の Minimal API バックエンド Web API サービス |

各テンプレートは `template.yaml`（入力フォーム・実行ステップ）と `skeleton/`（生成物の中身）で構成されます。詳細は各テンプレートの README を参照してください。
